# COD Africa Calculator

Pricing and profit calculator for cash-on-delivery e-commerce in Africa (Congo-Brazzaville, Cameroon, Gabon, Chad, Côte d'Ivoire, Togo, Benin, Burkina Faso, Mali, Niger, Senegal, Guinea, DR Congo, Mauritania).

- Mauritania: 7 $ per delivered order, 15 $/kg shipping, 50 $/month storage (spread over delivered orders)
- Per-country fulfilment fee and China shipping rate per kg (from the partner price list, editable)
- Product cost, weight, units per order, CPL, confirmation and delivery rates
- Profit per delivered order, break-even CPL and price, recommended price
- Funnel and P&L, what-if grid, country comparison, stock planner

Single static file: open `index.html` in a browser, or serve it with GitHub Pages.
The previous simple calculator is kept in `old/`.
